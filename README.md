# Fahim — Portfolio V2

A premium editorial portfolio for Syed Fahim Muddasir, built with Next.js, React and Tailwind CSS.

## Direction
- Editorial / art-direction visual language
- Responsive typography-first hero
- Selected work grid with hover interactions
- About, services and contact sections
- SEO-ready metadata
- Minimal monochrome palette with acid-lime accent

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.
